Project Work

2026 · Conference Poster

Impact of Reference Database Selection on Species-Level Microbiome Profiling

First Author · with N.T. Devika · Dept. of Bioinformatics, SASTRA

  • Evaluated how reference database choice (SILVA vs. Greengenes) changes species-level taxonomic assignment, using a host–pathogen infection model.
  • Built SG_consensus, an integrated database merging SILVA and Greengenes to improve taxonomic consistency and reduce database-dependent variability.
  • Constructed microbial co-occurrence networks with SparCC (|r| ≥ 0.5, p < 0.01), comparing interaction patterns across all three databases.
  • Showed that database selection significantly shifts downstream ecological interpretation; partial conflict resolution achieved, with refinement ongoing.

QIIME 2 · SparCC · SILVA · Greengenes · 16S rRNA
